# Incident Journal Sample

## Incident Title

Suspicious Phishing Email Reported by Employee

## Date

2026-03-13

## Summary

An employee reported a suspicious email that appeared to be a password reset request. The message used urgent language and included a link that prompted immediate action. Based on the indicators present, the email was treated as a possible phishing attempt.

## Initial Observation

The sender appeared to imitate a trusted source, but the sender address and link destination looked inconsistent. This raised concern that the message was designed to trick the user into revealing credentials or visiting a malicious page.

## Indicators

- Unexpected password reset request
- Urgent wording intended to pressure the user
- Suspicious sender domain
- Link destination did not match the visible text

## Triage Assessment

The email was reviewed as a likely phishing message. At the time of reporting, there was no evidence that the user clicked the link or entered credentials.

## Response Actions

- Advised the user not to click the link
- Preserved the email for review
- Reported the message as suspicious
- Recommended blocking the sender if confirmed malicious
- Noted the incident for awareness and follow-up

## Outcome

The incident was contained at the reporting stage. No account compromise or system impact was confirmed.

## Lessons Learned

This scenario highlights the importance of user awareness, early reporting, and careful review of sender information and embedded links. Even a simple phishing attempt can become a larger security issue if it is not identified quickly.
