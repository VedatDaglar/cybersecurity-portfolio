# Wireless Security Basics

## Goal

I want to understand how Wi-Fi security has changed over time.

| Security type | What I learned |
|---|---|
| WEP | It is old and not safe to use today. |
| WPA | It improved WEP, but it is also old. |
| WPA2 | It is widely used and provides stronger protection. |
| WPA3 | It is newer and provides improved protection. |

## Key points

- Wi-Fi security helps protect the connection between my device and the wireless network.
- An open Wi-Fi network does not have the same protection as a WPA2 or WPA3 network.
- A secure Wi-Fi network does not mean every website is safe. I should still check for HTTPS.

## What I understood

WEP and WPA are older options. If my devices support WPA3, I would prefer it. WPA2 is also a common option when WPA3 is not available.
